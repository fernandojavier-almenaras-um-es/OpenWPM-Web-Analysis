# OpenWPM Web Analysis

This repository contains the source code of a [OpenWPM fork](OpenWPM/README.md) and a [fork](OpenWPM-Data-Analytics/README.md) of an analysis tool, which treats the results. Additionally, the [results](Results/OpenWPM/README.md) of executing both tools with the top 1000 most visited websites in April 2024, as well as the [list of webpages](Tranco/README.md) generated by Tranco, are available.

The following trackers have been considered:

- Web fingerprinting.
  - Audio Context.
  - Canvas.
  - Canvas Font.
  - WebGL.
  - WebRTC.
  - JavaScript Enumeration.
  
- Web analysis tools.
  - Google Analytics.
  - Meta Pixel.
  - Microsoft Universal Event Tracking.
  - Hotjar.
  
- Web storage.
  - Local Storage.
  - Session Storage.
  - Indexed Database.
  
- First and third party cookies.
  - Session.
  - Host only.
  - Secure. With both the Secure and HTTP only attributes.
